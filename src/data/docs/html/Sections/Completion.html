13. Command Line Bash Completion¶

Bash shell completion for options is available. It should work similarly for zsh.

To use option completion you need:

  • python-argcomplete package installed

  • shell program completion enabled.

  • to source output of a script to register the command line completion

13.1. python-argcomplete¶

Install the argcomplete pythong package. On Arch, as usual do:

pacman -Syu --needed python-argcomplete

13.2. bash program completion¶

It is likely active unless you disabled it with shopt -u progcomp. You can turn it on when needed or in ~/.bashrc with

shopt -s progcomp

13.3. Register wg-tool completion¶

You can add this to your .bashrc or for testing purposes simply run it in a terminal:

eval "$(register-python-argcomplete wg-tool)"

13.4. Using Completion¶

Now you when you start typing an option simply press the TAB key to get the completions.

For example, with

wg-tool --<TAB>

It should display the available options. Or

wg-tool --nets<TAB>

Will list options beginning with –nets
